# Movie Search

Навчальний проєкт для пошуку фільмів через OMDb API. Застосунок створений на чистому JavaScript з використанням Vite.

## Опис

Користувач вводить назву фільму в поле пошуку, після чого застосунок надсилає запит до OMDb API та показує список знайдених фільмів. Для кожного фільму відображаються назва, рік, тип і постер.

Якщо постер відсутній або посилання на нього некоректне, використовується локальне fallback-зображення:

```text
public/assets/no-img.jpg
```

## Функціонал

- пошук фільмів за назвою;
- debounce для зменшення кількості запитів до API;
- мінімальна довжина запиту: 4 символи;
- перевірка повторного запиту, щоб не шукати те саме двічі;
- повідомлення про стан пошуку та помилки;
- checkbox для очищення попередніх результатів;
- fallback-зображення для фільмів без постера;
- адаптивна сітка карток;
- hover-ефекти для поля пошуку, карток і постерів.

## Встановлення

Встановити залежності:




## Основні частини коду

Уся логіка застосунку знаходиться у файлі:

```text
src/main.js
```

Основні функції:

- `createMovieApp()` створює HTML-структуру сторінки;
- `addStyles()` додає стилі через JavaScript;
- `debounce()` відкладає виконання пошуку;
- `getData()` отримує дані з OMDb API;
- `addMovieToList()` створює картку фільму;
- `clearMoviesMarkup()` очищає список результатів;
- `inputSearchHandler()` обробляє введення користувача.

## Навчальна мета

Проєкт демонструє роботу з DOM, подіями, асинхронними запитами, API, debounce, обробкою помилок і динамічним створенням інтерфейсу без використання фреймворків.
